# 🧮 Calculadora em Python

Este projeto é uma calculadora simples desenvolvida em Python para praticar lógica de programação e versionamento de código utilizando Git e GitHub.

---

# 🚀 Tecnologias utilizadas

- Python
- Git
- GitHub

---

# 📂 Código do projeto

```python
# Calculadora simples em Python

numero1 = 12
numero2 = -38

resultado = numero1 + numero2

print("Resultado:", resultado)
```

---

# ▶️ Como executar

Clone o repositório:

```
git clone https://github.com/Geraldo-ops/calculadora-python.git
```

Entre na pasta:

```
cd calculadora-python
```

Execute o programa:

```
python3 calculadora.py
```
